# ROBOREAN
>strong and sturdy; like an oak tree.

A simple word scoring application.


What you need:
- Docker Compose.
- Buildx (plugin).
- A [Merriam Webster](https://dictionaryapi.com/) API key (free!).
- An open port 3000.

How to run the application:
- clone the repository.
- Insert your key (MW_API_KEY=\[YOUR KEY]) into a .env file in the root of the obscurity folder. 
- run:
```bash
cd roborean
docker compose up --build
```
- Enjoy a coffee while it spins up.
